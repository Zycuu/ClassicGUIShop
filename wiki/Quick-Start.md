# Quick Start

1. Back up `config/guishop/` and install the 1.4.0 universal JAR on a supported Fabric server.
2. Install the same JAR on your matching Fabric client and join with `guishop.admin` permission (default OP level 2 or higher).
3. Press F8, create a category, and choose its icon.
4. Add a selected item or your exact held stack. Set buy/sell prices; zero disables that side.
5. Arrange categories and move listings between them, and exit Arrange mode to review the draft's chest layout.
6. Apply, then open `/shop` to check the real player menu and test buying/selling.
7. Review Transactions and Changes in Adminshop.

`/bal`, `/econ bal <player>`, `/econ leaderboard`, `/shop pay`, `/sellhand`, and `/worth` remain player commands. `/adminshop` opens the new client editor, requiring the matching client mod and `guishop.admin` (default OP 2). `/ident`, automatic catalog generation, legacy admin subcommands and old folder commands remain removed.
