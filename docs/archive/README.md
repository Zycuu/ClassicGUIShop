# Historical documentation archive

These files preserve development history and earlier implementation notes. They are not the current operator instructions.

- [Original porting notes](PORTING_NOTES.md): behavior and limitations of the initial Bukkit-inspired implementation.
- [Pre-cleanup README](pre-release-cleanup/README.md): the complete accumulated development/release notes as they existed before the 1.4.0 documentation cleanup.
- [Pre-cleanup wiki](pre-release-cleanup/wiki/Home.md): previous operator pages, including superseded Alpha/Beta workflows.
- [Historical changelogs](../changelog/README.md): original version notes moved out of the repository root without changing their bytes.

Current documentation starts at the [README](../../README.md) and [wiki home](../../wiki/Home.md). Source and wiki Git bundles were also preserved locally before cleanup.

The [preservation manifest](preservation-manifest.json) records the original path, archive path, and SHA-256 for all 34 preserved files. Historical text is intentionally unchanged, including references to retired controls or earlier file locations.
