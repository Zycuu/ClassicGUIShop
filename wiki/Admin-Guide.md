# Admin Guide

The administrator interface and every administrator command have been removed from the 1.4.0 development base. They will be rebuilt.

Existing listings, manual prices, balances, enchantment offers, folders, and unavailable-listing data are preserved. There are currently no in-game tools for editing these records or importing new listings.

For necessary manual edits, stop the test server, back up `config/guishop/`, edit the appropriate JSON file, and restart. Preserve exact stack data. This development base is for testing the rebuild.
